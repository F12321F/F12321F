- 尚不能證明 Supabase 遠端已套用 schema.sql，也不能宣稱已完成真實新增或四項遠端破壞測試。
- GitHub Pages 管理 API 同樣被此環境拒絕；Pages 啟用、部署成功與手機新增尚待確認。
- 提供的工具無修改環境網路政策功能；需由環境擁有者在設定介面放行網域。未以其他伺服器或代理繞過政策。

## 放行後的最後驗收
1. 確認 Supabase SQL、GRANT、RLS、CHECK，且舊資料保留。
2. 執行 verify-live.cjs，四項各一次：指定已完成、亂填類別、更新與刪除本次虛構紀錄。保留實際 HTTP 與錯誤碼。
3. 合併 PR、啟用 GitHub Actions Pages，等待部署成功。
4. 手機與電腦開 Pages，新增並讀回同一筆；以成功的真實截圖更新操作說明。
5. 使用者親自檢查文件及審查意見；不能代稱使用者已檢查或已核准。
