# 旅行分帳本

多人旅行共用的記帳程式。幣別以新台幣為主，另支援 40 多種外幣；自動計算每人收支與最少筆數的轉帳方式。

- 網頁版：用瀏覽器開啟 `travel-expense/index.html`
- Android App：下載 [travel-split.apk](https://github.com/F12321F/F12321F/releases/download/travel-split-latest/travel-split.apk)
- 加到手機主畫面（PWA）、自行建置與使用說明：見 [`travel-expense/README.md`](travel-expense/README.md)
